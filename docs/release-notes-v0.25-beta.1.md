A complete graphical installer for the **Seal of Evil HD Patch**, with **Windows 11 compatibility improvements**, **1080p / 1440p (2K) / 4K** support, HD opening screens, and widescreen main-menu artwork.

Download **SealHDSetup-Portable-Test.exe**, close the game, select its installation folder, and install. **All HD-patch components are included; no earlier patch package is required.** Backup and restore are included. No CMD or PowerShell commands are needed.

This beta includes the missing Windows manifest treatment, targeted compatibility-setting handling, and safe artwork fallback when the HD presentation path is unavailable.

**Beta limitations:** Local game startup/menu rendering and restoration passed. The remote Intel i7-8550U computer and the final elevated/UAC installation flow remain unverified. If IV50 decoding is unavailable, original opening and ending videos are skipped automatically; their files are preserved. Complete original-movie playback support is not implemented.
