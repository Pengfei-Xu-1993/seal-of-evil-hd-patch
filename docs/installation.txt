Seal of Evil HD Patch v0.26

A complete graphical installer for Windows 11 compatibility improvements,
18 resolution choices, borderless fullscreen, HD opening/menu artwork, and
original-frame-driven main-menu animation.

Developed and implemented by OpenAI Codex. The project owner only reviews
and approves the work and did not write the code.

DOWNLOAD AND INSTALL

1. Close the game.
2. Download SealHDSetup.exe from:
   https://github.com/Pengfei-Xu-1993/seal-of-evil-hd-patch/releases/tag/v0.26
3. Run the EXE and allow Windows administrator permission when requested.
4. Select the game folder containing SOE.EXE. Steam library folders are
   detected automatically; Browse can select another location.
5. Choose a resolution and install. The default is 1920x1080.
6. Start the game normally through Steam.

The EXE contains all HD-patch components. No earlier package, separate
update, CMD, or PowerShell commands are required. The interface supports
Chinese and English. An unknown input loader receives one backup-and-replace
confirmation; installation checks the supported game files before writing.

UPDATING AND TEMPORARY DIAGNOSTIC SETTINGS

Use the same EXE to update an existing installation. Select the desired
resolution again. The installer preserves its first-install backup history
and does not manage saved games.

Installation sets [Assets] MainMenu=1, replacing the temporary MainMenu=0
workaround. Manually renamed movie files are not renamed automatically.
If Movie\Start.dat.SealHD-disabled exists and Start.dat does not, rename it
back to Start.dat after installation. Do not overwrite an existing Start.dat.

ORIGINAL VIDEOS

If IV50 decoding is unavailable, the original opening and ending videos are
skipped automatically; their files are preserved. No decoder is bundled or
installed. The enhanced static opening screens are a separate feature.

RESOLUTIONS

The installer and Options > Screen Resolution share these modes:

Original 4:3:
800x600, 1024x768

16:9 and common near-16:9 displays:
1280x720, 1360x768, 1366x768, 1536x864, 1600x900,
1920x1080, 2560x1440, 3840x2160

16:10:
1280x800, 1440x900, 1600x1000, 1680x1050, 1920x1200,
2560x1600, 2880x1800, 3840x2400

Use the left/right game controls to select a size. OK applies and saves it;
Cancel preserves the applied selection. Existing profile IDs remain stable.
Higher resolutions increase the old renderer's workload; start with 1080p.

MAIN-MENU ANIMATION

The patch uses original frame sequences from the player's installation to
reconstruct lower and side fire, rising steam, curtain movement, and local
firelight on nearby objects while retaining the HD textures. It is not a
physical lighting simulation or a pixel-identical reproduction of the
original composition. [Assets] FireAnimation=0 keeps the HD scene static.

RESTORE

Close the game, run SealHDSetup.exe, select the same folder, and choose
Restore original files. The installer restores its recorded original files
and game-specific compatibility settings. Saved games are preserved.
Backups remain in SealHD-installer-backups. Later independent file or
compatibility-setting changes are preserved and reported instead of being
silently overwritten.
