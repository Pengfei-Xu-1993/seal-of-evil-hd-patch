# Development and content attribution

The Seal of Evil Save Editor was **developed and implemented by OpenAI Codex**. The publisher reviewed the work and did not write the code.

This publication contains the editor's own C# source, build configuration and English documentation. The downloadable program contains the editor, its item-generation worker and its actor-generation worker.

Original game executables, libraries, data tables, artwork, dialog resources and saved games are supplied by the user's own installation. They are not included in this publication. The original game and its associated names and content remain the property of their respective rights holders.

The editor includes its own Chinese reference-name dictionary. Those reference translations are explicitly identified in the interface and are not claimed to be the original Chinese retail localization. Other Chinese display names are selected from reviewed annotations in the user's installed tables at runtime. Neither presentation path changes an item's native identity or translates the game's interface.

No private reference repository, save fixtures, decoded game catalog, internal research captures or original game binaries are included in the public source folder or release archive. The validation summary describes local evidence and its limits without publishing those materials.

The application's bronze-and-jade icon is newly generated artwork. Its PNG, ICO and generation prompt are included in `assets/`. Skill and equipment icons are decoded at runtime from the user's own installed resources and are not bundled with the editor.
